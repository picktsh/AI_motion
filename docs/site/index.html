本机运行 · 不依赖数据库 · 以磁盘文件为事实来源

AI Motion Desk

围绕 .motion 模板的本地可视化工作台：把项目、素材、配音与成片收在一处，重动作交给命令台任务与外部 AI 工具，面板负责观测、回显与整理。

模板

导入包结构校验、逐文件 sha256、来源锁定与凭据扫描；按版本落盘，旧版本不覆盖。

项目

编号式目录（YYMMDDNNN），文稿、报价、生成与步骤进度一条线；素材删除前核对实例引用。

作品

独立作品清单只收已出成片，发布配置、封面与文案就绪状态随清单回带。

文件

目录树浏览、只读预览与文件级操作；文本读写 API 供外部 AI 回写，带 sha256 冲突检测。

观测

本机文件变动经 SSE 推送到面板，按项目/产物/素材/模板四域刷新，不靠轮询。

检索

项目、模板与素材一次搜；顶栏入口，结果按域分组并可直达资源。

上手三步

  1. 装依赖：Node.js ≥ 22（corepack 启 pnpm）、uv、ffmpeg；Python 环境用 pnpm setup:python。
  2. 起服务：pnpm dev:server 与 pnpm dev:web，打开 127.0.0.1:5577。
  3. 导模板：官网下载 .motion 后导入，进「创作」建项目。
pnpm dev:server   # 127.0.0.1:5599
pnpm dev:web      # 127.0.0.1:5577

边界

服务只绑定本机回环，资源访问限 studio 白名单目录；访问密钥可选开启，Key 只存本地配置并以掩码展示。演示站为静态页面，不连任何后端。

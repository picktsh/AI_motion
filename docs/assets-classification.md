# 素材归类口径（input / output 拆分）

> 对应 roadmap #190。本文先定目录与归类口径、迁移路径；接口与页面改造按本文分步落地，不做无迁移方案的硬切。

## 一、为什么要拆

当前配音 TTS 的试听样例、合成分段落在 `studio/tts` 下，被全局素材库当作「音频素材」统计，导致素材数与实际可复用资源不符：中间产物混进了源素材清单，筛选和复用都会被干扰。

口径参考 ComfyUI 的 input / output 思路：input 放用户提供或可跨项目复用的源素材，output 放本次生成的中间产物与成品；素材库只扫 input 一侧。

## 二、归类定义

### input：可复用源素材（进素材库）

| 类别 | 位置 | 说明 |
| --- | --- | --- |
| 项目引用素材 | `studio/projects/<id>/input/assets/` | 截图、人物图、配图、项目专用 BGM 等，由用户或外部 AI 归集 |
| 公共素材 | `studio/assets/`（规划） | 跨项目复用的图片、视频、BGM、公共音色参考 |
| 公共音色库 | `studio/tts/samples/` 中标记为可复用的音色样例 | 仅试听样例本身；合成产物不算 |

判定要点：可以被再次引用、不依附于某一条成片的中间过程，才算 input。

### output：生成产物与中间产物（不进素材库，只在项目详情内展示）

| 类别 | 位置 | 说明 |
| --- | --- | --- |
| 项目配音 | `studio/projects/<id>/input/voice.mp3`、`voice.json` | 按本条文稿合成的旁白，属项目产物 |
| 配音分段 | `studio/tts/segments/` | 逐句合成缓存，中间产物 |
| 试听样例 | `studio/tts/samples/` 中单次生成、未登记为公共音色的条目 | 试听用途，不作为素材复用 |
| 字幕 | 项目字幕条、`.vtt` | 配音后按语音回写的产物 |
| 渲染实例 | `studio/projects/<id>/instance-*` | 模板渲染中间产物，不进清单 |
| 成片与封面 | `studio/projects/<id>/output/` | 成品产物，走作品页展示，不走素材库 |
| 日志与临时文件 | `*.log`、`*.tmp`、上传缓存 | 过程文件 |

## 三、归属标记（配合 #184）

每条素材登记归属，公私划分沿用 publish-schema 的登记口径：

- `project:<id>`：归属某条项目，仅该项目详情与该项目素材视图出现；
- `public`：公共素材，跨项目复用，进全局素材库；
- 未登记归属的项目内文件，默认按所属项目归类，不进公共清单。

## 四、迁移路径（分步，不硬切）

1. **文档口径（本轮）**：本文锁定 input/output 定义与位置映射；磁盘路径暂不迁移。
2. **接口分类字段**：盘点接口在条目上补 `kind: 'input' | 'output'` 与 `owner: 'project:<id>' | 'public'` 字段；读侧按位置推断，不改写磁盘登记。
3. **页面过滤**：素材库只列 `kind=input` 且归属公共或当前项目的条目；配音分段、试听样例、成片、实例移出素材库，分别在配音页、项目详情、作品页展示。
4. **登记收敛**：公共音色样例在配置里显式标记 `public`；未标记的试听样例按 output 处理。
5. **物理迁移（远期，视需要）**：确有目录调整需求时，再把公共素材从项目目录迁到 `studio/assets/`，旧路径保留兼容读取。

## 五、边界约定

- 素材库统计口径只数 input；output 的数量在项目详情或对应业务页单独展示，不混入素材计数。
- 接口引用素材时只给编号或相对路径，不在提示词里混排绝对路径与转码串（与 #185 口径一致）。
- 归类有歧义的文件（如项目目录里的 BGM）：先按项目归属处理，登记为公共后再进全局清单。

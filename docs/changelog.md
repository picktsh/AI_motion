# #130 创作链路重做（模板→文稿→报价→生成→发布）

- 新增 `studio/projects/<id>` 项目模型与 `/api/v1/projects`：创建、详情、列表、报价、正式生成、成片发布配置、文件清单、日志。
- 模板导入保留原始 `.package.motion`，个人包运行不再依赖 Downloads 路径；项目实例由包内 `new` 初始化。
- 前端菜单重排为 创作 / 模板 / 项目 / 发布 / 配音 / 任务 / 设置；模板详情新增“用这个模板创作”。
- 创作页只列可运行的个人包；项目详情串起文稿、报价（TTS/编排/上传清单）、生成、成片预览、4:3+3:4 封面与发布文案。
- 报价与正式生成均走包内 `assistant/motion.mjs api … expert`；额度不足时保留官方原始错误与 run.log。
- 已知：像素包 expert 报价 2 额度（TTS 1 + 编排 1），当前官方账号 `remaining=0`，真实出片被官方拒绝 `insufficient_credits`。

## #134 内置模板接入项目链路

- 原因：项目运行器只认个人 `.motion`，内置模板没有原始包，所有内置模板都被判“缺少包”。
- 修复：项目按模板类型分流。内置模板走 `studio/template/adapter.py prepare → render`，PATH 前插 `studio/bin`，自动补 `user-assets/cover.png`；兼容 `studio/template` 旧路径 ID。
- 内置模板建项目时用包内 `examples/text-only.json` 生成本期输入，时长由模板原生窗口决定（当前 8s）。
- 实测：`第一次刷到-202611221804` 42.4s 出片 19MB，状态 done；4:3/3:4 封面与 publish.txt 已生成。
- 个人包仍走官方云端，余额不足时按原逻辑拦截。

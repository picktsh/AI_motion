# 改动记录（Changelog）

> 记账规则：后续每个需求或功能改动都追加一笔。最新记录在最上方。
> 每条格式：日期 · 类型 · 改动内容 · 关联任务。
> 类型：**新增** 新功能 / **修复** 缺陷 / **调整** 体验或结构改动 / **文档** 文档变更。
> 本文件只记已交付的变更，不记代码实现手段、勘误与调试现象，也不记待办；规划与待确认事项见 [roadmap.md](./roadmap.md)，需求归属见 [requirements.md](./requirements.md)。

## 0.1.0 · 2026-11-22

- 新增 · #109 后端命令台任务接口：白名单命令注册（plan/prepare/preview/render/tts:voice/tts:samples），提供任务提交、列表、快照、增量日志与取消；内存任务表按渲染/默认分组并发，子进程独立进程组终止，超时、缺依赖与路径越界收口为统一错误体；本地 bin 目录注入子进程 PATH

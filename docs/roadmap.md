# 路线图（Roadmap）

> 登记尚未开工、方案或选型待确认的事项，随项目进度动态调整。已交付变更见 [changelog.md](./changelog.md)，需求归属与状态核对见 [requirements.md](./requirements.md)，项目定位与阶段目标见 [vision.md](./vision.md)。
> 每条格式：`- #编号 事项描述`；无编号为内部工程项。编号对应需求台账任务号。
> 优先级口径：二期近期 > 二期中段 > 二期后段 > 三期；工程与体验优化项穿插进行。

## 二期近期：命令台执行闭环（优先）

- 二期命令台：prepare、preview、render、tts 白名单执行，日志回流，长任务异步轮询，模板依赖安装联动；先在本机跑通一条完整出片链路
- 健康状态定时轮询：后端自动恢复后前端不需手动刷新即回到已连接态
- 命令台依赖联动：node_modules、studio/tts/.venv、studio/bin 就位检查与安装引导
- 后端监听可配置：HOST/PORT 由环境变量配置，默认回环；CORS 按来源白名单收紧，不再用全开放 *
- 访问密钥鉴权：后端通过本地配置文件或环境变量设置访问密钥（不入库）；面板经请求头携带密钥，不放 URL 查询参数；后端统一校验，未通过返回 401；写接口与命令执行必须校验；页面掩码展示、日志不打印、支持轮换；访问密钥与 AI 厂商 key 分开存放
- 运行配置说明：About 或设置页展示监听地址与端口、访问密钥状态、资产白名单目录、外部依赖路径与版本、AI provider 状态；各配置项的来源与缺省值在文档列明

## 二期中段：.motion 兼容层

- 目录迁移与模板依赖：旧路径迁至 `studio/templates/<id>` 并保留兼容；templates.lock.json 来源锁定与 SHA256 校验；.motion 拖拽导入与凭据扫描
- 模板包静态校验：ZIP 边界、路径穿越、重复/别名条目、符号链接、解压比、引用完整性、integrity.json 哈希比对；不执行未知代码
- #94 参数只读视图：按 `params.schema.json` 渲染参数概要、类型范围与 preset 预览；默认值由宿主显式应用，schema 不自动注入
- 版本与 profile 声明：明确标注支持的 specVersion 与 runtime profile，未知版本前缀不盲接受，不认识的字段保留并警告

## 二期后段：素材与作品管理

- #65 标准化写 API：发布配置读写、BGM 公共库与选用回写、404 语义修正（当前 publish.json 不存在被误归 403）、studio 白名单与路径越界校验；后端默认回环，跨机访问需鉴权与 CORS 配套；前端表单编辑保存
- #68 作品与视频条目菜单拆分：新增「作品」菜单管发布清单，「视频条目」留工程回显；数据边界、路由命名、id 传递待对齐
- #69 模板真实本地下载：占位按钮已放；一键下载需后端拉取落盘接口；官网为 .motion 模板包，非 AI 权重模型
- #67 波形与统一播放器重做：柱宽自适应、进度显示、点击 seek、统一控制条，替换散落原生 controls；引 wavesurfer.js 或继续自绘，选型待拍板

## 三期：AI 助手

- #70 多厂商 BYOK AI 助手：用户配置自己的 API Key，适配火山引擎、Qwen、DeepSeek、OpenAI 兼容（含 Codex 类）等提供商；生成发布文案与参考封面，结果经后端写盘；提供商、模型档位、额度与提示词模板待定
- AI 配置与密钥安全：provider、baseURL、模型名、Key 存入本地配置（不入库、不进日志、页面掩码展示）；优先本地后端代理转发，纯前端直连作为降级并标注风险；发起调用前明示将消耗用户本人模型额度
- Provider 适配层：统一 chat 补全（可选图像生成）接口，优先复用 OpenAI 兼容协议接入多家，差异厂商单独适配；错误与限流统一处理

## 工程与体验优化（穿插进行）

- 运行时配置层：后端地址、AI 提供商与密钥可在页面配置；读取优先级为页面本地设置 > 构建期 env > 内置兜底；配置与业务代码分离
- 契约不兼容提示：协议版本在运行时比对，前后端版本不兼容时前端给出明确提示
- #95 About 页可视化：图形化展示阶段路线图、能力地图、服务架构拓扑图与运行配置说明，替代纯 markdown 表格；组件与配色沿用现有克制主题；阶段、条目与配置数据从单一来源取，避免文档和页面两套口径
- 前端体验补全：Naive UI 全量引入拆包；折叠状态持久化；骨架屏与错误分支实测；全局检索；`<768px>` 移动端视图适配
- #93 Markdown 渲染：更新日志页改用轻量成熟的 Markdown 渲染库（markdown-it 或 marked，选型待确认）直接渲染 changelog.md、roadmap.md，替换当前手写条目解析；评估产物体积与 HTML 消毒防 XSS，新依赖先确认再引入

## 开源准备与对外展示（三期后段评估）

- GitHub Pages 演示站：纯静态项目介绍、界面截图与动图、特性清单、上手说明；只放可再分发 demo 素材，不连本机后端
- 服务器部署（远期评估，形态待定）：对比公开只读 API 与远程完整工作台两种方案；鉴权、加密、目录隔离、CORS 待方案确定后再设计；无论哪种都不接私有工程、个人 key 与成片，不代理个人交付包
- 内核独立发包评估：`packages/shared` 稳定后评估是否独立发布，供其他兼容工具复用
